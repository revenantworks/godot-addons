# Revenantworks Godot addons

Free addons for Godot 4 by Revenantworks, one folder each. Each release is a zip on this repo's
Releases page; install it from the Godot Asset Library or the Godot Asset Store, or copy its
`addons/` folder into your project. Every addon is Apache-2.0 unless its folder says otherwise.

## Pixel FX Starter

Five free pixel-perfect 2D shaders for Godot 4.7: outline, hit flash, palette swap, dissolve and pixelate.

[folder](pixel-fx/) · [releases](https://github.com/revenantworks/godot-addons/releases?q=pixel-fx-v)
