# Support

Read the addon's own `README.md` first (each addon has a folder in this repository).

| You need | Go to |
|---|---|
| An answer or an idea | [Discussions](https://github.com/revenantworks/godot-addons/discussions) |
| To report a bug or ask for a feature | [New issue](https://github.com/revenantworks/godot-addons/issues/new/choose) |
| To report an accessibility barrier | [New issue](https://github.com/revenantworks/godot-addons/issues/new/choose), "Accessibility barrier" |
| To report a security problem | [Private form](https://github.com/revenantworks/godot-addons/security/advisories/new) |

Issues are read when time allows. No reply time is promised and no custom work is offered.

Do not paste secrets, real names, personal paths, or email addresses into any public space.

## Support period

**Support period.** Pixel FX Starter 0.x has a best-effort support period until 2027-11-23. Security fixes are not guaranteed, and only the latest
release in that line is considered. After that date nothing is expected, and it is end-of-life.
Feature updates are not promised. End-of-life dates for every version are listed here. The date
may be renewed if the addon is still maintained; silence is not a promise.

| Addon | Version line | Best-effort fixes until | Status |
|---|---|---|---|
| Pixel FX Starter | 0.x | 2027-11-23 | supported, best effort |

Support is best effort and unpaid. No reply time, fix time, update or fitness for any purpose is
promised. Donations support the work. They buy nothing: every release, fix and the source stay free for everyone.
