# Support

Read the addon's own `README.md` first (each addon has a folder in this repository).

| You need | Go to |
|---|---|
| An answer or an idea | [Discussions](https://github.com/revenantworks/godot-addons/discussions) |
| To report a bug or ask for a feature | [New issue](https://github.com/revenantworks/godot-addons/issues/new/choose) |
| To report an accessibility barrier | [New issue](https://github.com/revenantworks/godot-addons/issues/new/choose), "Accessibility barrier" |
| To report a security problem | [Private form](https://github.com/revenantworks/godot-addons/security/advisories/new) |

Issues are read when time allows. No reply time is promised and no custom work is offered.

Do not paste secrets, real names, personal paths, or email addresses into any public space.
