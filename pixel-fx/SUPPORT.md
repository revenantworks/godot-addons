# Support

Read the `README.md` first.

| You need | Go to |
|---|---|
| An answer or an idea | [Discussions](https://github.com/revenantworks/godot-pixel-fx/discussions) |
| To report a bug or ask for a feature | [New issue](https://github.com/revenantworks/godot-pixel-fx/issues/new/choose) |
| To report an accessibility barrier | [New issue](https://github.com/revenantworks/godot-pixel-fx/issues/new/choose), "Accessibility barrier" |
| To report a security problem | [Private form](https://github.com/revenantworks/godot-pixel-fx/security/advisories/new) |

Do not paste secrets, real names, personal paths, or email addresses into any public space.

Issues are read when time allows. No reply time is promised and no custom work is offered.

## Support period

**Support period.** Pixel FX Starter 0.x gets security fixes until 2027-11-23. Only the latest
release in that line gets fixes. After that date it gets no fixes of any kind and is end-of-life.
Feature updates are not promised. End-of-life dates for every version are listed here. The date
may be renewed if the addon is still maintained; silence is not a promise.

| Version line | Security fixes until | Status |
|---|---|---|
| 0.x | 2027-11-23 | supported, best effort |

Support is best effort and unpaid. No reply time, fix time, update or fitness for any purpose is
promised. Donations, if you choose to make one, buy nothing: no support, no priority, no features.
